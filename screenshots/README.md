# 📱 Folder Screenshot Aplikasi

Folder ini berisi dokumentasi visual tangkapan layar antarmuka pengguna (*User Interface*) aplikasi yang disematkan ke dalam [`README.md`](../README.md):

- `home_screen.png` : Tangkapan layar katalog utama Digimon dalam format 2 kolom responsif (`LazyVerticalGrid`).
- `detail_screen.png` : Tangkapan layar halaman detail lengkap Digimon (Level, Tipe, Atribut, dan Gambar).
- `state_screen.png` : Tangkapan layar penanganan status reaktif antarmuka pengguna (`UiState.Loading` dan `UiState.Error`).
- `create_screenshots.py` : Skrip otomasi untuk menghasilkan/memperbarui aset visual beresolusi tinggi menggunakan Python Pillow.
